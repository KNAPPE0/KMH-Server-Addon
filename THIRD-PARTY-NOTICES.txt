SixLabors.ImageSharp 4.1.3
--------------------------
Copyright (c) Six Labors
Six Labors Split License, Version 1.0
https://github.com/SixLabors/ImageSharp/blob/main/LICENSE

Used by the server media resolver to decode WebP images that the KMH
client cannot decode, and to re-encode them as PNG (static) or animated
GIF (animated) so they can be displayed in game.

The Six Labors Split License grants use under the terms of the Apache
License 2.0 to open source and source-available software, among other
qualifying categories. KMH is distributed under that clause. Release
builds read a free Six Labors Community licence key at build time; the
key is not part of this distribution.

Security note: 4.1.3 carries the fixes for the October 2026 advisories.
KMH also restricts ImageSharp to the formats it needs: the resolver
registers only PNG, JPEG, GIF, WebP and BMP decoders, decodes with
metadata skipped and ICC profiles never converted, drops any metadata a
decoder still keeps before re-encoding, never encodes TIFF and never
runs histogram equalization. It also encodes the leaderboard PNG
described below; that path only ever encodes an image KMH drew itself
and decodes nothing.
